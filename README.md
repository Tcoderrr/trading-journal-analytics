Trading Journal Analytics Dashboard

A self-directed financial analytics project built in Power BI, analysing 33 live trades from a PostgreSQL trading journal.

Tools used: Power BI Desktop, Power Query, DAX, PostgreSQL

What the dashboard covers:

Performance overview — total trades, win rate, P&L by month
Edge analysis — P&L by session, direction, signal type, and macro alignment
Psychology and performance correlation
Cumulative equity curve

Key finding: Pre-trade psychology rating was the single most predictive variable — 84.62% win rate at rating 8 versus 35% at rating 7.
